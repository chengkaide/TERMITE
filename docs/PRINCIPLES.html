这份文档说明 R/termite_core.R 每一步在算什么、为什么这么算、以及哪里容易出错。 公式与代码一一对应，可以直接对照阅读。

0. 一句话概括

TERMITE 做的事情是：

把 LA-ICP-MS 测到的同位素计数率（cps），经过「扣背景 → 内标归一 → 同位素换算 → 用参考物质定标」， 换算成以 µg/g 为单位的元素含量，并按检出限和离群判据做截断。

整条链路没有任何"绝对定量"的环节——它不计算剥蚀量、传输效率或电离效率， 而是把所有这些未知量统统打包进一个由参考物质测出来的相对灵敏度因子 RSF 里。 理解这一点，后面所有公式都会变得很自然。

1. 符号表

符号 含义 单位
j 待测同位素（如 Ca43、U238） —
IS 内标同位素（如 Ca43），必须有已知含量 —
I_j 扣背景后的净计数率 cps
A_j 同位素丰度（AtomGewIsoAbund_NIST.csv 第 2 行） —
M_j 同位素原子量（同表第 1 行） g/mol
C_IS 内标元素含量：样品用输入值，参考物质用推荐值 µg/g
C_j^cert 参考物质中元素 j 的推荐含量（Standards_GeoReM.csv） µg/g
RSF_j 相对灵敏度因子 —

2. 数据读取与行号约定

原始文件形如：

line 1 : D:\Daten\2015\10_Oktober\151019a.B\019.D      ← 采集信息
line 2 : Intensity Vs Time,CPS
line 3 : Time [Sec],Mg25,Al27,P31,Ca43,...              ← 同位素表头
line 4 : 0.156,100.00,400.01,3300.51,100.00,...         ← 数据起点

界面上填的 header_line = 3、signal_line = 4、first_blank = 5 …… 全部是文件的真实行号（从 1 计）。 内核在内部换算成矩阵行号：

矩阵行号 = 真实行号 − (signal_line − 1)

原脚本的坑：它把 Line.of.Header / Line.of.Signal 各自先减 1 再到处用， Line.of.Signal 既当"跳过的行数"又当"要减掉的偏移量"，读者极容易看错。 本内核把两件事分开：skip = signal_line - 1，偏移量单独减。

分隔符由仪器决定：Agilent（四极杆）导出用逗号，Element2（SF-ICP-MS）导出用制表符， 且 Element2 的表头带分辨率后缀（如 Ca43(LR)），需要用 resolution 参数剥掉。

数据列从第 2 列开始取，共 n_iso 列；第 1 列是时间。

3. 背景扣除（gas blank）

选一段没有剥蚀的行（first_blank : last_blank），对每个同位素取中位数（或均值）：

bg_j = median( I_j[first_blank : last_blank] )

再从信号区的每一行里逐列减掉：

I_j(t) = raw_j(t) − bg_j         t ∈ [first_signal, last_signal]

为什么用中位数：空白段的计数率分布右偏（偶发的高计数脉冲），中位数比均值稳健。 示例数据里两者差别不大，但对真实数据中位数明显更可靠。

负值怎么办：扣完背景后必然出现负值（纯噪声）。原脚本在点分析里把它们截断为 0， 在线扫描里不做处理。截断会带来正偏倚——低含量样品被系统性抬高。 所以本内核把它做成显式开关 clip_negative，默认保持与原脚本一致，但你可以关掉。

4. 内标归一

R_j = I_j / I_IS

这一步消掉的是信号强度的整体漂移：激光能量波动、传输效率变化、基质剥蚀量差异， 它们对同一时刻所有同位素的影响近似相同，取比值就抵消了。

内标元素必须满足两个条件：样品中含量已知、在样品中均匀分布。 示例用 Ca43（碳酸盐样品的基体元素）。岩石类样品常用 Si29 或 Ca43。

⚠️ column_IS 填的是原始文件里的列号（含时间列）。 示例文件里 Ca43 是第 5 列，所以填 5 —— 不是 4。

5. 离群剔除

对每个文件、每个同位素，在 R_j 序列上：

M_j = median(R_j)
上界 = M_j × (1 + m)
下界 = M_j × (1 − m)
   窗口外的点 → NA            （m 默认 30%）

然后对剩下的点取均值，得到该文件的代表性比值。

这一步的性质要说清楚：

  • 它是围绕中位数的固定百分比窗口，不是 MAD、不是 3σ。对强偏态数据不稳健。
  • 如果 M_j = 0（该同位素在样品中基本测不到，中位数落在 0 上）， 则下界 = 上界 = 0，所有非零值都会被剔除，结果变成 NA。 示例数据里 La139、Ce140、Y89 大面积输出 NA，就是这个原因，不是计算失败。
  • 想保留全部数据，把「离群检验」关掉即可。

6. 同位素换算：从"计数率比"到"质量比"

测得的是同位素的计数率，想得到的是元素的质量比。两步修正：

① 丰度修正。质谱计数的原子数与丰度成正比，所以元素 j 的原子数流 ∝ I_j / A_j。

② 原子量修正。质量流 ∝ 原子数流 × 原子量，所以 m_j ∝ (I_j / A_j) · M_j。

把两者相除：

m_j / m_IS = (I_j / A_j · M_j) / (I_IS / A_IS · M_IS)
           = R_j · (A_IS / A_j) · (M_j / M_IS)

记换算因子

Iso_j = (A_IS / A_j) · (M_j / M_IS)

代码里就是 iso_factor。对内部标准元素自己，Iso_IS = 1。

7. 参考物质定标：RSF

到第 6 步为止，我们只得到了相对于内标的质量比。 再乘上内标含量 C_IS，就得到一个"未校正浓度"：

C_j^uncorr = Iso_j · R_j · C_IS

它成立的前提是：仪器对待测元素 j 和内标元素 IS 的灵敏度完全相同。 这个假设不成立（重元素灵敏度低、不同元素电离能不同），于是用参考物质来量它。

对每个参考物质文件：

RSF_j = C_j^uncorr(ref) / C_j^cert(ref)

RSF_j > 1 表示仪器对 j 的响应比内标"高"（或者说，按未校正公式算出来的浓度偏高）， 所以最终要把未校正浓度除以它：

C_j = C_j^uncorr / RSF_j ,        RSF_j = mean over all reference files

关于 RSF 的三点注意：

  1. 对内部标准元素本身 RSF = 1（因为 C_IS^uncorr = C_IS^cert = C_IS）。 所以输出表里内标元素的浓度恒等于你输入的 C_IS，它不是测出来的，是输入值。 示例里 Ca 永远显示 400003.81，就是这个道理，不要当成分析结果去解读。
  2. RSF 把「剥蚀量 × 传输效率 × 电离效率」全部吸收了。因此样品与参考物质的基体必须接近， 否则 RSF 不可转移（这是 LA-ICP-MS 定量的根本限制）。
  3. 应用的「校准 RSF」页给出了每种参考物质各自的回收率（实测 RSF ÷ 全局均值）。 如果同一参考物质的多个文件之间回收率漂移很大，说明信号不稳定或样品室有污染， 此时全局 RSF 的可靠性要打折。

8. 检出限 LoD

TERMITE 用的公式是：

LoD_j = 3 σ_j(blank) / mean(I_j^sample) × C_j^cert(RefMat1)

读法：把空白区计数率的 3σ，用当前样品自身的灵敏度折算成浓度。 量纲上 cps/cps × µg/g = µg/g，没问题。

但有两点需要明确：

  • 分母用的是当前样品的净计数率，而不是参考物质定标出来的灵敏度。 严谨的写法应该是 LoD_j = 3σ_j(blank) · C_j^cert / I_j^cert（用参考物质定义灵敏度）， TERMITE 相当于假设"样品与参考物质灵敏度相同"。 对含量与参考物质差很远的样品，这个 LoD 会有偏差。 把它理解为该样品自身的相对检出限更合适。
  • 当 3σ_j(blank) = 0 时（空白段计数完全恒定），原脚本会把分子替换成 1， 于是 LoD = 1 / mean(I_j) × C_j^cert —— 这个值与标准差无关，量纲上的"3σ"含义完全丢失。 属于兜底的补丁，本内核在「复刻模式」下同样复刻它，但默认模式下会保留 0。

LoD 的汇总：对每个参考物质文件各算一次 LoD，然后取中位数作为最终 LoD， 用于把结果表里低于 LoD 的单元格置为 NA。

原脚本的坑：线扫描脚本在选取"哪些文件的 LoD 参与中位数"时， 用的是参考物质的种类数而不是文件数，导致第一个参考文件被漏掉 （示例数据中剖面有 242 个单元格因此改变了 NA 状态）。 本内核默认取全部参考文件，legacy_lod = TRUE 可复刻原行为。

关于内标：一段补充

第 4 节的推导假设「内标元素在样品中含量已知且分布均匀」。同一批样品基体不同时， 这个假设会破。判断办法：看上面第 4 节的推导反过来用 —— 哪个元素在剥蚀段信号最强，样品大概就以它为主量。 tools/run_termite.R 与界面上的「计算主量同位素」都是干这个的。

若一批样品分成几类基体，要么分批跑，要么接受某一类的结果不可用。 把它硬套一个内标，得到的是数字，不是含量。

内标的替代方案：有些矿物（氟磷灰石、云母）没有可靠的内标，或不想先做 EPMA， 可以改用矿物化学式归一化（AYCF 家族）——用矿物结构式（a.p.f.u. / 电荷平衡）替代内标， 省去 EPMA。见 FORMULA_CAL.html，入口是 termite_run_formula()。

数据导入的细节（支持哪些仪器格式、别名表怎么配、参考物质名称怎么对） 见 IMPORT.html。

9. 相对标准偏差与可疑点

对每个样品点：

RSD_j = sd(R_j) / mean(R_j)          （用未做离群剔除的 R_j 序列）

若某点的 RSD_j 高于全部点的均值，就在结果图里标红，提示该点可能不均匀（击穿到包裹体、 表面不平、剥蚀到裂隙等）。

10. 线扫描的两个特有问题

① x 轴。距离由时间换算：

distance(t) = (t − t_0) × v / 1000        [s]·[µm/s]/1000 → [mm]

t 取自文件第 1 列，t_0 是激光开剥第一行的时间。 原脚本把 t 取成文件最前面 N 行的时间，与实际数据行错位，整条曲线平移了 0.78 µm。 本内核默认按数据行对齐（legacy_time_axis = TRUE 可复刻原行为）。

② 参考物质的积分窗口与样品不同。两个入口脚本的默认值就不一样：

参数 点分析 线扫描（参考物质）
空白区 5 – 124 5 – 124
信号区 180 – 440 130 – 545
样品信号区 — 143 – 6890

拿点分析的 180–440 去跑线扫描的参考物质，RSF 会偏 0.5% 左右。 界面上切换模式时会自动套用对应的默认值。

③ 负值。线扫描是对每一行出结果，不取均值，所以背景噪声导致的负值会让剖面出现 负的浓度。原脚本此处不截断（截断与否在界面上可选）。

11. 容易踩的坑：清单

  1. column_IS 是原始文件列号（含时间列），不是同位素序列的第几个。
  2. 内标元素本身的输出浓度等于输入值，不要当结果解读。
  3. M_j 用的是"同位素原子量"，不是元素原子量。表里 Mg25 的原子量是 24.304。
  4. 积分窗口是文件真实行号，改一个数就会改变整条链路的输出。
  5. 离群窗口是固定百分比，中位数为 0 时会把所有非零点剔掉 → 输出 NA。
  6. RSF 不可跨基体转移：样品基体与参考物质差太远时，结果不可信。
  7. LoD 用的是样品自身的灵敏度，把它当"绝对检出限"解读要谨慎。
  8. 负值截断会引入正偏倚，低含量样品尤其明显。
