# 无内标校准：矿物化学式归一化（AYCF 家族）

这份文档说明 `R/termite_formula.R` 在算什么、为什么能省掉内标元素、以及哪里容易出错。
它是**独立的校准策略**，不修改 `termite_run()`（内标法）的数值路径，由 `termite_run_formula()`
单独调用。引用来源：

- Liu et al. (2008) *Chem. Geol.* 257:34–43 —— AYCF，无水矿物归一化到 100 wt%
- Zhang et al. (2022) *JAAS* 37:1793 —— 氟磷灰石，用结构式补 P 与 F
- Zhang et al. (2023) *JAAS* 38:1387 —— 云母，用结构式补 K 与 OH(F)

---

## 0. 一句话概括

> 传统内标法需要先用 EPMA 测出样品里某个元素（内标）的含量 `C_IS`，用来归一化剥蚀产率。
> 矿物化学式归一化**用矿物本身的化学式（a.p.f.u. / 电荷平衡）替代内标**：
> 测得的所有阳离子必须满足该矿物的结构式约束，这个约束定出一个「归一化因子」，
> 从而把相对浓度换算成绝对浓度，全程不需要 EPMA。

对无水矿物，这个约束是**电荷平衡**（所有阳离子电荷总和 = 阴离子 O²⁻ 电荷总和）；
对含 F/Cl/OH、或含高电离能 P / 层间 K 的矿物，这些组分 ICP-MS 测不准，
就**按结构式理论补出来**，再从归一化总和里剔除。

---

## 1. 为什么要绕开内标

内标法（见 [PRINCIPLES.md](PRINCIPLES.md) 第 4 节）的两个前提是：

1. 内标元素在样品中**含量已知**（通常靠 EPMA 或全岩分析）；
2. 内标元素在样品中**均匀分布**。

麻烦在于：

- **EPMA 是额外的、更贵的实验**，而且样品要抛光、镀膜、可被电子束打到；
- 有些矿物的"自然内标"不好找：氟磷灰石里 Ca 是主量但 P 测不准；云母里 K 在层间位、
  LA 剥蚀时分馏严重，用 K 做内标不可靠；
- 样品太小、或只想快速筛一批数据时，先补 EPMA 再归算，流程被拉长。

矿物化学式归一化正好对症：**矿物化学式本身就是最"硬"的约束**——你测了白钨矿，
就该得到 CaWO₄ 的阳离子比例，这个比例不依赖 EPMA。

---

## 2. 核心思想：电荷归一化 ≡ 氧化物归一化到 100 wt%

先讲一个等价关系，它是整套方法的数学根基。

把「元素 i」换算成「氧化物 i」时，每个元素对应一个换算因子：

```
l_i = 1 + (z_i / 2) · (M_O / M_i)
```

其中 `z_i` 是元素价态（决定氧化物里带几个 O），`M_O` / `M_i` 是氧 / 元素的原子量。
例：Ca（z=2，M=40.078）→ `l_Ca = 1 + (2/2)·(15.999/40.078) = 1.399`，即 CaO/Ca。
Si（z=4）→ `l_Si = 1 + (4/2)·(15.999/28.0855) = 2.139`，即 SiO₂/Si。

于是：

```
氧化物总质量 = Σ C_i · l_i = Σ (n_i · M_i) · (1 + (z_i/2)·M_O/M_i)
             = Σ n_i·M_i + (M_O/2)·Σ n_i·z_i
```

如果所有阳离子的电荷总和被固定为 `Σ n_i·z_i = 2·n_O`（`n_O` 是化学式里的氧原子数），
那么：

```
氧化物总质量 = Σ n_i·M_i + M_O·n_O = 矿物分子量 M_total
```

也就是说：**「阳离子电荷平衡」和「元素氧化物总和 = 100 wt%」在数学上完全等价**。
AYCF 原文说的是后者（把测得元素写成氧化物、归一化到 100%），
本实现直接做前者（电荷平衡），更省一步、也更容易把"测不准的元素"从和里抠出去。

## 3. 灵敏度 λ：多参考物质回归

内标法里的 RSF 是「未校正浓度 ÷ 推荐值」，同样，这里需要先有一个把 cps 变成
"未归一化浓度"的灵敏度因子 λ：

```
λ_i = Σ C_i^rm / Σ cps_i^rm         （对所有定标参考物质求和）
```

它和内标法共用参考物质推荐值表（`Standards_GeoReM.csv`），区别在于：
λ 是「每单位 cps 对应的 µg/g」，而 RSF 是「相对内标的无因次校正因子」。

有了 λ，任何样品的**未归一化浓度**是：

```
C'_i = cps_i · λ_i
```

它还不是真实浓度——因为剥蚀产率、基体差异等因素会让 `C'_i` 整体偏大或偏小一个**共同因子**。
矿物结构式约束就是用来定这个共同因子的。

---

## 4. 三种归算模式

### 4.1 无水矿物（anhydrous）—— 电荷归一化

适用于白钨矿 CaWO₄、锡石 SnO₂、锆石 ZrSiO₄ 这类**所有阴离子都是 O²⁻** 的矿物。

```
n_i  = C'_i / M_i                    # 未归一化摩尔数
F_f  = (2·n_O) / Σ n_i·z_i           # 化学式因子（电荷平衡定出）
apfu = n_i · F_f                     # 换算成 a.p.f.u.（每单位分子式原子数）
C_i  = apfu · M_i / M_total × 10⁶    # M_total = Σ apfu·M_i + n_O·M_O
```

`F_f` 的意义：它把「cps 里那些未知的剥蚀/传输/电离因子」一次性吸收掉，
使得阳离子电荷恰好配平。这也是为什么它叫"化学式因子"——它让测量结果**落在化学式上**。

### 4.2 氟磷灰石（apatite）—— 结构式补 P 与 F

`Ca₅(PO₄)₃F`：**P 高电离能、F 不电离**，ICP-MS 都测不准。做法：

- Ca 位（除 P 位外的阳离子）apfu 和 = 5 → 定出 `F_f = 5 / Σ n_ca`
- P 位（P + Si + As）apfu 和 = 3 → **P = 3 − Si − As**（Si、As 若测得到就从和里扣）
- F = 1，O = 12（结构式常数，硬编码进归算）

```
F_f  = 5 / Σ_{Ca 位} n_i
Fn_P = 3 − Fn_Si − Fn_As
M_total = Σ apfu·M_i + Fn_P·M_P + Fn_F·M_F + 12·M_O
```

### 4.3 云母（mica）—— 结构式补 K 与 OH(F)

`X Y₂₋₃ Z₄ O₁₀ (OH,F)₂`：**K 在层间位**，LA 剥蚀时分馏强、参考物质里 K 也常偏低，测不准。
Zhang et al. (2023) 的 AYCF² 做法：

- Y+Z 位（非层间阳离子）电荷归一化到 **21**（总 22，X 位整体按 +1 计）→ 定出 `F_f`
- X 位（Na + K + Rb + Cs + Ca + Ba + Sr）apfu 和 = 1 → **K = 1 − 其余层间阳离子**
- 挥发性组分全按 OH 计：OH = 2，O = 10（F 与 OH 原子量相近，含 F 云母近似成 OH）

```
F_f   = 21 / Σ_{Y+Z 位} n_i·z_i
Fn_K  = 1 − Σ_{X 位} apfu
M_total = Σ apfu·M_i + Fn_K·M_K + 2·(M_O + M_H) + 10·M_O
```

## 5. 使用方式

```r
source("R/termite_core.R"); source("R/termite_formula.R")   # 或直接 source 整个 R/

cfg <- termite_defaults("spot")          # 目前只支持点分析
cfg$dir <- "<数据目录>"
cfg$layout <- "flat"                     # 或 "dir"
cfg$ref_names <- c("SRM 610", "SRM 612")

res <- termite_run_formula(cfg, mineral = "scheelite")
tab <- termite_formula_table(res)        # 导出成数据框
```

矿物参数在 `TERMITEScriptFolder/mineral_formulas.csv`，内置 6 种（无此文件时自动用内置表）：

| name | 化学式 | mode | 说明 |
|---|---|---|---|
| scheelite | CaWO₄ | anhydrous | 白钨矿 |
| cassiterite | SnO₂ | anhydrous | 锡石 |
| zircon | ZrSiO₄ | anhydrous | 锆石 |
| fluorapatite | Ca₅(PO₄)₃F | apatite | 氟磷灰石 |
| muscovite | KAl₂(AlSi₃)O₁₀(OH,F)₂ | mica | 白云母 |
| biotite | K(Mg,Fe)₃(AlSi₃)O₁₀(OH,F)₂ | mica | 黑云母 |

想加新矿物：在 CSV 里加一行（`name / formula / mode / n_O / n_F / n_OH / excluded`）。
`excluded` 是「测不准、要按结构式理论补」的元素，目前归算函数里 P / K 是写死的
（对应 apatite 补 P、mica 补 K）；其余模式无需 excluded。

## 6. 与内标法的关系（重要）

| | 内标法 `termite_run()` | 化学式归一化 `termite_run_formula()` |
|---|---|---|
| 归一化依据 | 内标元素含量 `C_IS`（EPMA） | 矿物结构式（电荷 / apfu） |
| 定标 | RSF（参考物质） | λ（参考物质） |
| 需要 EPMA | **要** | **不要** |
| 前提 | 内标已知且均匀 | 知道矿物化学式 + 价态假设正确 |
| 支持线扫描 | 是 | 目前否（只 spot） |

两者共用：读数据层（`termite_import.R`）、参考物质推荐值表、同位素原子量/丰度表、文件分类。
**它们是并列的两条路**，不会互相影响——`termite_run()` 的逐位对拍测试
（`tests/test-parity.R`）在加了本模块后依然原样通过。

## 7. 局限与注意事项

1. **λ 仍然依赖参考物质**。省掉的是 EPMA，不是定标本身；样品与参考物质基体差异大时
   λ 同样不可转移（和 RSF 的局限同源）。
2. **价态是假设**。默认价态表按地学常规（Fe→Fe²⁺、Mn→Mn²⁺、W→W⁶⁺ 等）写死，
   若你的矿物里元素价态不同（如含 Fe³⁺），电荷平衡会偏，需要覆盖
   `termite_run_formula(cfg, mineral, valence = c(...))`。
3. **测不准的元素按化学式"理论补"**，它们的浓度是**约束算出来的**，不是测出来的。
   例如磷灰石的 P、云母的 K 与 OH——这些数字的正确性取决于结构式假设对不对。
4. **X 位 apfu 和 = 1 可能为负**：若测得的其它层间阳离子（Na/Ca/Ba…）apfu 之和 > 1，
   云母的 `K = 1 − Σ` 会变负，说明该样品根本不是（纯）云母，结果要警惕。
5. **只支持点分析**。线扫描的无内标校准（逐点 a.p.f.u. 归一化）尚未实现。

## 8. 数值自检

`tests/test-formula.R` 用「构造已知成分的矿物 → 反推它会产生什么 cps → 喂回归算函数」
的方式做纯代数还原验证（相对偏差 < 1e-8）：

- 白钨矿：Ca / Sr / W 浓度、a.p.f.u.、电荷平衡全部还原；
- 氟磷灰石：Ca / Sr / Mn / Si 还原 + P 理论补；
- 白云母：Na / Al / Si 还原 + K 理论补；
- `mineral_formulas.csv` 解析（6 种矿物、含逗号的化学式加引号）；
- 真实白钨矿数据端到端冒烟：W 中位数落在化学计量值 ±5% 内。

```bash
Rscript tests/test-formula.R
```
