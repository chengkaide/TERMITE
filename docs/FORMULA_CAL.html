这份文档说明 R/termite_formula.R 在算什么、为什么能省掉内标元素、以及哪里容易出错。 它是独立的校准策略，不修改 termite_run()（内标法）的数值路径，由 termite_run_formula() 单独调用。引用来源：

  • Liu et al. (2008) Chem. Geol. 257:34–43 —— AYCF，无水矿物归一化到 100 wt%
  • Zhang et al. (2022) JAAS 37:1793 —— 氟磷灰石，用结构式补 P 与 F
  • Zhang et al. (2023) JAAS 38:1387 —— 云母，用结构式补 K 与 OH(F)

0. 一句话概括

传统内标法需要先用 EPMA 测出样品里某个元素（内标）的含量 C_IS，用来归一化剥蚀产率。 矿物化学式归一化用矿物本身的化学式（a.p.f.u. / 电荷平衡）替代内标： 测得的所有阳离子必须满足该矿物的结构式约束，这个约束定出一个「归一化因子」， 从而把相对浓度换算成绝对浓度，全程不需要 EPMA。

对无水矿物，这个约束是电荷平衡（所有阳离子电荷总和 = 阴离子 O²⁻ 电荷总和）； 对含 F/Cl/OH、或含高电离能 P / 层间 K 的矿物，这些组分 ICP-MS 测不准， 就按结构式理论补出来，再从归一化总和里剔除。

1. 为什么要绕开内标

内标法（见 PRINCIPLES.html 第 4 节）的两个前提是：

  1. 内标元素在样品中含量已知（通常靠 EPMA 或全岩分析）；
  2. 内标元素在样品中均匀分布。

麻烦在于：

  • EPMA 是额外的、更贵的实验，而且样品要抛光、镀膜、可被电子束打到；
  • 有些矿物的"自然内标"不好找：氟磷灰石里 Ca 是主量但 P 测不准；云母里 K 在层间位、 LA 剥蚀时分馏严重，用 K 做内标不可靠；
  • 样品太小、或只想快速筛一批数据时，先补 EPMA 再归算，流程被拉长。

矿物化学式归一化正好对症：矿物化学式本身就是最"硬"的约束——你测了白钨矿， 就该得到 CaWO₄ 的阳离子比例，这个比例不依赖 EPMA。

2. 核心思想：电荷归一化 ≡ 氧化物归一化到 100 wt%

先讲一个等价关系，它是整套方法的数学根基。

把「元素 i」换算成「氧化物 i」时，每个元素对应一个换算因子：

l_i = 1 + (z_i / 2) · (M_O / M_i)

其中 z_i 是元素价态（决定氧化物里带几个 O），M_O / M_i 是氧 / 元素的原子量。 例：Ca（z=2，M=40.078）→ l_Ca = 1 + (2/2)·(15.999/40.078) = 1.399，即 CaO/Ca。 Si（z=4）→ l_Si = 1 + (4/2)·(15.999/28.0855) = 2.139，即 SiO₂/Si。

于是：

氧化物总质量 = Σ C_i · l_i = Σ (n_i · M_i) · (1 + (z_i/2)·M_O/M_i)
             = Σ n_i·M_i + (M_O/2)·Σ n_i·z_i

如果所有阳离子的电荷总和被固定为 Σ n_i·z_i = 2·n_O（n_O 是化学式里的氧原子数）， 那么：

氧化物总质量 = Σ n_i·M_i + M_O·n_O = 矿物分子量 M_total

也就是说：「阳离子电荷平衡」和「元素氧化物总和 = 100 wt%」在数学上完全等价。 AYCF 原文说的是后者（把测得元素写成氧化物、归一化到 100%）， 本实现直接做前者（电荷平衡），更省一步、也更容易把"测不准的元素"从和里抠出去。

3. 灵敏度 λ：多参考物质回归

内标法里的 RSF 是「未校正浓度 ÷ 推荐值」，同样，这里需要先有一个把 cps 变成 "未归一化浓度"的灵敏度因子 λ：

λ_i = Σ C_i^rm / Σ cps_i^rm         （对所有定标参考物质求和）

它和内标法共用参考物质推荐值表（Standards_GeoReM.csv），区别在于： λ 是「每单位 cps 对应的 µg/g」，而 RSF 是「相对内标的无因次校正因子」。

有了 λ，任何样品的未归一化浓度是：

C'_i = cps_i · λ_i

它还不是真实浓度——因为剥蚀产率、基体差异等因素会让 C'_i 整体偏大或偏小一个共同因子。 矿物结构式约束就是用来定这个共同因子的。

4. 三种归算模式

4.1 无水矿物（anhydrous）—— 电荷归一化

适用于白钨矿 CaWO₄、锡石 SnO₂、锆石 ZrSiO₄ 这类所有阴离子都是 O²⁻ 的矿物。

n_i  = C'_i / M_i                    # 未归一化摩尔数
F_f  = (2·n_O) / Σ n_i·z_i           # 化学式因子（电荷平衡定出）
apfu = n_i · F_f                     # 换算成 a.p.f.u.（每单位分子式原子数）
C_i  = apfu · M_i / M_total × 10⁶    # M_total = Σ apfu·M_i + n_O·M_O

F_f 的意义：它把「cps 里那些未知的剥蚀/传输/电离因子」一次性吸收掉， 使得阳离子电荷恰好配平。这也是为什么它叫"化学式因子"——它让测量结果落在化学式上。

4.2 氟磷灰石（apatite）—— 结构式补 P 与 F

Ca₅(PO₄)₃F：P 高电离能、F 不电离，ICP-MS 都测不准。做法：

  • Ca 位（除 P 位外的阳离子）apfu 和 = 5 → 定出 F_f = 5 / Σ n_ca
  • P 位（P + Si + As）apfu 和 = 3 → P = 3 − Si − As（Si、As 若测得到就从和里扣）
  • F = 1，O = 12（结构式常数，硬编码进归算）
F_f  = 5 / Σ_{Ca 位} n_i
Fn_P = 3 − Fn_Si − Fn_As
M_total = Σ apfu·M_i + Fn_P·M_P + Fn_F·M_F + 12·M_O

4.3 云母（mica）—— 结构式补 K 与 OH(F)

X Y₂₋₃ Z₄ O₁₀ (OH,F)₂：K 在层间位，LA 剥蚀时分馏强、参考物质里 K 也常偏低，测不准。 Zhang et al. (2023) 的 AYCF² 做法：

  • Y+Z 位（非层间阳离子）电荷归一化到 21（总 22，X 位整体按 +1 计）→ 定出 F_f
  • X 位（Na + K + Rb + Cs + Ca + Ba + Sr）apfu 和 = 1 → K = 1 − 其余层间阳离子
  • 挥发性组分全按 OH 计：OH = 2，O = 10（F 与 OH 原子量相近，含 F 云母近似成 OH）
F_f   = 21 / Σ_{Y+Z 位} n_i·z_i
Fn_K  = 1 − Σ_{X 位} apfu
M_total = Σ apfu·M_i + Fn_K·M_K + 2·(M_O + M_H) + 10·M_O

4.4 绿柱石 / 电气石（fixed）—— 固定配位阳离子扣除

有一类矿物，结构式里某个（或几个）主量阳离子的配位数固定，但它们 ICP-MS 测不准（或信号不可靠）：

  • 绿柱石 Be₃Al₂Si₆O₁₈：Be 质量小、电离能高、还常受通道水/碱金属干扰，测不准； 但 Be 在结构式里固定 3 个。
  • 电气石 XY₃Z₆(T₆O₁₈)(BO₃)₃(OH,F)₄：B 是轻元素、等离子体里挥发性强、记忆效应重， 测不准；Si 是主量、高浓度信号易饱和；两者在结构式里分别固定 3 和 6 个。

这些「测不准但配位数固定」的阳离子，就按化学式固定它们的 a.p.f.u.，从阴离子电荷里 扣除，其余可测阳离子再做电荷归一化。这是 4.1 无水矿物的直接推广：

anion_charge = 2·n_O − n_OH                              # OH⁻ 比 O²⁻ 少 1 个负电荷
charge_target = anion_charge − Σ z_fixed·apfu_fixed      # 可测阳离子要配平的电荷
F_f   = charge_target / Σ_{可测} n_i·z_i
M_total = Σ apfu·M_i + Σ apfu_fixed·M_fixed + n_O·M_O + n_OH·M_H + n_F·M_F

具体到两种矿物：

矿物 fixed n_O n_OH 可测阳离子电荷目标
绿柱石 Be₃Al₂Si₆O₁₈ Be:3 18 0 2·18 − 3·2 = 30
电气石 …O₁₈(BO₃)₃(OH,F)₄ B:3;Si:6 31 4 2·31 − 4 − (3·3+6·4) = 25

电气石的 OH 按 4 个计（V₃W 位全按 OH，F 与 OH 原子量相近、电荷相同，近似成立）， 和云母的处理一致。注意电气石的假设明显多于无水矿物，见第 7 节第 6 条。

5. 使用方式

source("R/termite_core.R"); source("R/termite_formula.R")   # 或直接 source 整个 R/

cfg <- termite_defaults("spot")          # 目前只支持点分析
cfg$dir <- "<数据目录>"
cfg$layout <- "flat"                     # 或 "dir"
cfg$ref_names <- c("SRM 610", "SRM 612")

res <- termite_run_formula(cfg, mineral = "scheelite")
tab <- termite_formula_table(res)        # 导出成数据框

矿物参数在 TERMITEScriptFolder/mineral_formulas.csv，内置 8 种（无此文件时自动用内置表）：

name 化学式 mode fixed 说明
scheelite CaWO₄ anhydrous — 白钨矿
cassiterite SnO₂ anhydrous — 锡石
zircon ZrSiO₄ anhydrous — 锆石
fluorapatite Ca₅(PO₄)₃F apatite — 氟磷灰石
muscovite KAl₂(AlSi₃)O₁₀(OH,F)₂ mica — 白云母
biotite K(Mg,Fe)₃(AlSi₃)O₁₀(OH,F)₂ mica — 黑云母
beryl Be₃Al₂Si₆O₁₈ fixed Be:3 绿柱石
tourmaline Na(Mg,Fe)₃Al₆Si₆O₁₈(BO₃)₃(OH)₄ fixed B:3;Si:6 电气石

想加新矿物：在 CSV 里加一行 （name / formula / mode / n_O / n_F / n_OH / fixed / excluded）。 - excluded 是「测不准、要按结构式理论补」的元素，归算函数里 P / K 是写死的 （对应 apatite 补 P、mica 补 K）； - fixed 是「配位数固定、要按结构式固定 a.p.f.u. 扣除」的阳离子（元素:个数，多个用 ; 分隔），走 fixed 模式的矿物（绿柱石/电气石）用它；其余矿物留空。

7. 局限与注意事项

  1. λ 仍然依赖参考物质。省掉的是 EPMA，不是定标本身；样品与参考物质基体差异大时 λ 同样不可转移（和 RSF 的局限同源）。
  2. 价态是假设。默认价态表按地学常规（Fe→Fe²⁺、Mn→Mn²⁺、W→W⁶⁺ 等）写死， 若你的矿物里元素价态不同（如含 Fe³⁺），电荷平衡会偏，需要覆盖 termite_run_formula(cfg, mineral, valence = c(...))。
  3. 测不准的元素按化学式"理论补"，它们的浓度是约束算出来的，不是测出来的。 例如磷灰石的 P、云母的 K 与 OH——这些数字的正确性取决于结构式假设对不对。
  4. X 位 apfu 和 = 1 可能为负：若测得的其它层间阳离子（Na/Ca/Ba…）apfu 之和 > 1， 云母的 K = 1 − Σ 会变负，说明该样品根本不是（纯）云母，结果要警惕。
  5. 只支持点分析。线扫描的无内标校准（逐点 a.p.f.u. 归一化）尚未实现。
  6. fixed 模式的假设更多，误差更大（尤其电气石）： - 固定阳离子的配位数被强制等于化学式——绿柱石 Be=3、电气石 B=3 与 Si=6。 真实矿物里这些位常被替代（电气石 T 位的 Si↔Al、绿柱石 Be↔Li/Na）， 假设偏差会直接反映到结果里。 - 电气石的 Fe 价态（Y 位 Fe²⁺ / Z 位 Fe³⁺）默认按 Fe²⁺ 计；含 Fe³⁺ 会偏。 - 电气石 OH/F 按 4 个 OH 近似，绿柱石通道水与通道碱金属被忽略。 因此绿柱石尚属稳健（只扣一个 Be），电气石只能当作半定量，结果要和内标法 或其它独立手段对拍后再用。

8. 数值自检

tests/test-formula.R 用「构造已知成分的矿物 → 反推它会产生什么 cps → 喂回归算函数」 的方式做纯代数还原验证（相对偏差 < 1e-8）：

  • 白钨矿：Ca / Sr / W 浓度、a.p.f.u.、电荷平衡全部还原；
  • 氟磷灰石：Ca / Sr / Mn / Si 还原 + P 理论补；
  • 白云母：Na / Al / Si 还原 + K 理论补；
  • 绿柱石：Al / Cr / Sc / Si 还原 + Be 理论补，电荷目标 = 30；
  • 电气石：Na / Ca / Mg / Fe / Al 还原 + B、Si 理论补，电荷目标 = 25；
  • mineral_formulas.csv 解析（8 种矿物、含逗号的化学式加引号）；
  • 真实白钨矿数据端到端冒烟：W 中位数落在化学计量值 ±5% 内。
