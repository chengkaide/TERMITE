交互式 LA-ICP-MS 微量元素数据归算工具——把原始 R 脚本重写为 纯 base R 内核 + Shiny 界面，解析、修错、讲清原理，并保证结果与原脚本逐位一致。

零外部依赖（只需 shiny） 点分析 / 线扫描 无内标矿物化学式归一化 与原脚本逐位一致 示例数据已脱敏
快速开始 阅读入门手册 GitHub 源码 ↗

原始 TERMITE（Simon A. Mischel 等，University of Mainz）是一套可用的定量脚本， 但线扫描分支存在若干致命错误，算法细节散落在 1150 行命令式代码里。 本项目保留全部算法定义，重写为可复用、可验证、可交互的形式——首次打开即用示例数据自动跑一遍。

主要功能

  • 数据导入按内容识别 Qtegra（iCAP）、Agilent、Element2 等格式，样品名从文件里读。
  • 点分析归算内标归一 → 同位素换算 → RSF 定标，输出 µg/g 浓度。
  • 线扫描剖面逐点归算为浓度–距离剖面，可输出元素对比值（如 Zr/Hf、Nb/Ta）。
  • 无内标公式法用矿物结构式替代内标元素，支持白钨矿、锡石、锆石、磷灰石、云母、绿柱石、电气石、磁铁矿、铬铁矿。
  • 区间选择逐点画信号曲线，在图上划定背景窗/信号窗，导出窗口建议并一键回填（不改动已有结果）。
  • 质量检查检出限截断、中位数 ±m% 离群剔除、参考物质回收率。
  • 一致性自检一键与原脚本对拍：点分析、线扫描最大相对偏差为 0，NA 模式一致。

两种定标策略

① 内标法（经典）

  • 需要一个已知含量的内标元素（如白钨矿用 W、锡石用 Sn）
  • 内标含量通常由 EPMA 事先测得
  • RSF 由参考物质回归，把剥蚀/传输/电离效率打包成一个经验因子
  • 适用面广，但不可跨基体转移

② 公式法（无内标，AYCF 家族）

  • 用矿物结构式电荷平衡归一，替代内标元素
  • 测不准的元素（磷灰石的 P/F、云母的 K/OH、绿柱石的 Be、电气石的 B/Si）按结构式理论补
  • 省去 EPMA，两种方法数学等价
  • 依赖矿物化学计量与价态假设，需按矿物选对模式

两种策略在同一个界面里切换：顶部导航共三页 ——「内标法归算」「无内标公式法」与「微量元素处理 · 区间选择」。 详见 docs/FORMULA_CAL.html。

快速开始

# 1. 唯一需要的包
install.packages("shiny")

# 2. 在仓库根目录启动（首次自动用示例数据跑一遍点分析）
shiny::runApp(".")

不启动界面也能批处理（tools/run_termite.R）：

Rscript tools/run_termite.R --dir "<数据目录>" --layout flat --auto \
  --ref "SRM 610,SRM 612" --qc "BIR-1G,BCR-2G" \
  --is 182W --is-conc 638500 --blank 25,60 --signal 70,118

应用案例

下面两个案例都用真实批次数据跑通，样品号已脱敏。 它们回答的不是“软件能不能跑”，而是两个更要紧的问题： 换一条定标路径，结果会不会变； 同一种矿物有多个归一化口径时，怎么判断哪个对。

案例 1

白钨矿：两种定标策略的交叉验证

一批真实白钨矿 · 40 个有效测点 · SRM 610 / 612 定标 · 点分析

同一份原始信号走两条路：一路用 W 作内标 （C_IS = 638500 µg/g），一路用 CaWO₄ 的电荷平衡归一。 两法在数学上等价，但独立实现之后会不会给出同一个答案？ 把 W 从对比里剔掉之后（内标法对它是零信息量）， 剩下的元素才是真正的交叉验证。

  • 内标法对 W 没有信息量：40 个测点全部等于输入的 638500 µg/g，批内 RSD = 0%
  • 公式法独立算出 W = 621701（范围 505929 ~ 626166），与 EPMA 标称值差 −2.6%
  • 主量一致：Ca 差 −1.2%；批内 RSD 内标法 12.3% → 公式法 6.4%
  • REE 总量差 −1.2%，La / Ce / Yb / Lu 单元素在 ±0.8% ~ ±2.5%
  • 偏离最大：Mg −10.2%、Ta +17.8%，均属低含量 / 跨基体敏感元素
  • 异常测点两法同时标红：S-A-10（W −20.8%、Ca −23.2%）——分歧有时是样品真相
案例 2

锆石：四种归一化口径的判别

一批真实锆石 · 30 个测点 · 42 个同位素通道 → 去重后 38 个元素

锆石有个便利：Zr、Si 的化学计量是已知的 （Zr 49.77 wt%、Si 15.32 wt%），于是“用哪条约束归一”这个问题 有了标准答案可以对照。把四种口径并排—— Zr 内标、Si 内标、公式法（固定 Si = 1）、公式法（含 Si 全配平） ——只有一种同时通过两道检验。

  • 主量氧化物总和：A 111.5 / B 89.2 / C 99.99 / D 99.99 wt%（100 wt% 是硬约束）
  • Si:(Zr+Hf) 摩尔比（理想 1.000）：A 1.235 / B 1.231 / C 1.016 / D 1.248
  • ⇒ 四个口径中只有「固定 Si = 1」自洽：两道检验同时通过，与实验室 AYCF 的 0.980 同向
  • 根因是 ²⁹Si 通道偏高约 24%：用硅酸盐玻璃标样定锆石基体，跨基体
  • 与实验室对照：C 的 SiO₂ 32.38 vs 31.68、ZrO₂ 64.44 vs 65.58 wt%，主量一致到 2% 以内
  • D 口径的用途：zircon_full 保留作交叉校验——两口径之差 ≈ 你自己的 ²⁹Si 偏了多少

界面结构：三页分工

数值一致性：最重要的一步

tests/test-parity.R 把内核在复刻模式下重跑，与原始脚本生成的基准输出逐列比对： 点分析 40×12、线扫描 6748×12 单元格最大相对偏差全部 0.000e+00，NA 模式完全一致。

另有 tests/test-app.R 用 shiny::testServer() 把服务端整条反应链跑一遍（点/线/公式法多组参数，无需浏览器）。 所有数值改动都做成开关，默认走修正模式，可切回复刻原脚本行为。
